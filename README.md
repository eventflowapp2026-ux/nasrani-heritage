# Nasrani Heritage Community

A public online community platform dedicated to preserving, explaining, and discussing Nasrani (St. Thomas Christian) heritage, traditions, liturgy, language, history, and research.

## Features

- **User System**: Registration, login, profiles with roles (Admin, Moderator, User)
- **Public Feed**: Reverse chronological posts with category filtering
- **Rich Post Creation**: Text, images, PDFs, audio uploads with rich text editor
- **Categories**: History, Liturgy, Syriac Language, Feasts, Research, Youth Questions
- **Engagement**: Likes, threaded comments, report system
- **PDF Export**: Auto-generated PDFs with QR codes for each post
- **Moderation Tools**: Admin dashboard for content moderation
- **Responsive Design**: Mobile-friendly heritage-inspired theme

## Tech Stack

- **Backend**: Django 4.2 (Python)
- **Frontend**: Bootstrap 5, Custom CSS
- **Database**: SQLite (development) / PostgreSQL (production)
- **Additional**: CKEditor, ReportLab, WeasyPrint, QR Code generation
